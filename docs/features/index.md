# Feature Maps

- [Permission Observation Recording](permission-observation-recording.md) — the plugin that records permission request lifecycles into the user-local observation database.
- [Permission Decision Review](permission-decision-review.md) — the skill that reads observations into a permission decision history and advises on permission policy.
- [Permission Policy Management](permission-policy-management.md) — the skill and agent that resolve effective policy and apply confirmed policy edits.
