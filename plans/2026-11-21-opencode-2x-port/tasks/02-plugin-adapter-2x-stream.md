- [ ] Capture or verify fixture shapes against v2.3.2 [`permission` schema](https://github.com/anomalyco/opencode/blob/v2.3.2/packages/schema/src/permission.ts), [`tool` schema](https://github.com/anomalyco/opencode/blob/v2.3.2/packages/schema/src/tool.ts), and [`shell` implementation](https://github.com/anomalyco/opencode/blob/v2.3.2/packages/core/src/tool/plugin/shell.ts). Cover “retains requested resources and location when OpenCode asks for permission”, “retains the request identity and outcome when OpenCode replies”, “rejects a request without an event location”, “reports an incomplete shell call when no final exit code is available”, “reports a failed shell call when the tool reports an error without an exit code”, and “reports a successful shell call when it exits with zero”. Also cover nonzero exits, malformed facts, non-shell completed calls with and without a result, and metadata exclusion. Run `bun test .opencode/plugins/permission-optimizer/test/event-adapter.test.ts`; expect red because the v2 adapter does not exist.
- [ ] Export `adaptV2PermissionEvent(value: unknown, clock: Clock)` and `adaptV2Completion(value: unknown, clock: Clock)`. Validate `{ type, data, location }`. An asked result carries request/session IDs, action, ordered resources, optional message/call IDs, absolute location directory, and receipt time. A reply carries request/session IDs, the `once`/`always`/`reject` outcome, and receipt time. A completion carries session, call and optional message/agent IDs, tool, timestamp, `success | failure | incomplete`, and nullable exit code. Narrow unknowns once; reject malformed required facts without leaking the payload. Ignore save hints, inputs and outputs. Shell final exit must be a finite integer; running or unknown exit is incomplete. Host-reported error is failure. Non-shell completion with no result is incomplete.
- [ ] Run the focused test, `bun run typecheck`, and `bun run test`; expect green for both adapters. Attach both coding-guideline audits; stage only Files paths and commit `feat: validate OpenCode two permission and completion events`.
